# resumo-lab-3
Criando um banco de dados no Microsoft Azure

Para a criação de um banco de dados no Microsoft Azure primeiramente devemos dar um nome ao banco de dados. seguido de selecionar um servidor o criá-lo se for necessário. Logo devemos informar qual vai der o tipo de autenticação e o modo de redundância que o nosso serviço vai ter.
Para finalizar é exibido um resumo do valor mensal a ser pago pelos serviços que foram selecionados seuguido de um botão para confirmar a criação dos serviços.
